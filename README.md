## ✨ Features

- **🤖 AI-Powered Generation:** Instantly generate comprehensive quizzes from PDFs, text files, or specific topics using Gemini AI.
- **🔄 Smart Paraphrasing:** Use AI to effortlessly reword existing questions while keeping the same difficulty and meaning.
- **🧠 Daily Challenges:** Play a fresh, AI-generated 10-question trivia challenge every single day.
- **📚 5 Interactive Question Types:**
  - Multiple Choice
  - True / False
  - Identification
  - Enumeration (Supports both strict sequential order and random order)
  - Re-arrange / Ordering (Interactive sorting)
- **📂 Collection Management:** Organize your quizzes into custom folders with personalized icons.
- **📥 Advanced Import/Export:** Share quizzes easily via `.qb` files, JSON uploads, or direct clipboard pasting.
- **🔊 Accessible Gameplay:** Built-in Text-to-Speech (TTS) to automatically read questions aloud.
- **🌗 Beautiful UI:** Seamless Light & Dark mode support

## 🛠️ Tech Stack

- **Framework:** [React Native](https://reactnative.dev/) / [Expo](https://expo.dev/)
- **State Management:** [Zustand](https://github.com/pmndrs/zustand)
- **Styling:** NativeWind (Tailwind CSS)
- **Icons:** React Native Heroicons
- **AI Integration:** Google Gemini API
- **Utilities:** Expo Speech, Expo FileSystem, Expo DocumentPicker
